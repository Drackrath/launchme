# launchme 0.4.3

Released 2026-10-29.

## Fixes

- **Aurelia: "Could not verify the Aurelia daemon identity" after updating Aurelia** (and every Aurelia
  feature failing, the app taking you for signed out): the old version's daemon kept running after an update and
  lost its identity marker. Launchme now ends its own helper's daemon when it has no marker or comes from an
  older installed version, so the next command starts a fresh one; anything else at the endpoint is still
  refused. Windows and Linux.
- **Aurelia: signing in with a QR code or with the account name and password did nothing**: these sign-ins now
  run in Launchme's own Aurelia process, as *Sign in using Aurelia's window* does, so the password and Steam
  Guard codes reach them.
- **Aurelia: Cloud saves → Sync now jumped to Aurelia's settings** when the session was not available: it now
  says why on the same page.
- **Aurelia's pages: Back could not be reached with the keyboard or a pad**: Up from the first row now moves to
  Back (✕ on the desktop window's first pages), Enter or A takes it.

## Changes

- **Aurelia: one sign-in page** (Settings → Library → Steam → *Manage Aurelia* → *Sign in*): Steam's QR code for
  the Steam Mobile app and, below it, the field for the account name and then the password, together, as on
  Steam's own sign-in; Backspace in the empty password field goes back to the name. *Sign in using Aurelia's
  window* is on the same page.
- **Aurelia: who is signed in**: the first row of Aurelia's settings is *Steam account* with its name, or *Sign
  in* with *Not signed in*; *Manage Aurelia* in the settings shows it too.
