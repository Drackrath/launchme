# launchme 0.3.3

Released 2026-10-28. A local build, not published on GitHub.

## New

- **Xbox account** (Settings → Library → *Xbox* ⚙ → **Account → Connect**): sign in with a Microsoft account and
  see its games next to the ones the Xbox app installed: bought games, Xbox Play Anywhere titles and, while
  subscribed, the PC Game Pass catalog, with Microsoft Store art. It works through **launchme-xbox**, Launchme's
  own open-source helper built on [Xodus](https://github.com/xodus-gaming/xodus) (source in `helpers/xbox`). The
  helper is not bundled: **Xbox helper → Download** fetches the pinned v0.1.0 (SHA-256 checked), **Remove**
  deletes it. Sign-in happens in the helper's own Microsoft window; tokens are encrypted with DPAPI. See
  [the Xbox guide](../docs/XBOX.md).
  - **Install** opens the game's page in the Xbox app (the Microsoft Store without it); the installed game
    then shows up by itself.
  - **Install through Launchme (experimental)** (same page, off by default): GDK games are downloaded by the
    helper straight into a folder you choose, with progress in **Downloads** and **Cancel download**. **Play**
    runs them through the helper, which gets a fresh license for every session (an ended Game Pass stops it),
    decrypts the game's encrypted files for the session and seals them again afterwards. **Uninstall** asks,
    then deletes the folder. Needs Gaming Services.

## Fixes

- Switching **Amazon Games** on in Settings → Library is kept after a restart (it was not saved).
