# launchme 0.1.2

Released 2026-10-25.

## New

- **Steam account switching** (Settings → Library → Launching → *Steam account switching*, on by default):
  Play on a game installed by another Steam account remembered on this PC closes Steam, makes it sign in to
  that account and then starts the game, the way Steam's own account switcher does. No passwords are
  involved: the account needs to have been signed in once with *Remember me*. While a Steam game is running
  the switch waits for you to close it, and games the signed-in account can play itself never switch.
- **Steam installs in the launcher** (Settings → Library → Launching → *Steam installs in the launcher*, on by
  default): Install on a Steam game opens Launchme's own dialog, in TV mode and in the desktop window, listing
  your Steam library folders with their free space (the roomiest one is preselected). Install puts the game's
  download request into that library and restarts Steam in the tray, which then downloads it there; progress
  shows in Launchme as usual. *Steam's install window* keeps Steam's own dialog.

## Changes

- **Flix**: the unfolding card now grows to both sides, pushing the tiles before it left and those after it
  right, as on Netflix; the first tile in view still grows to the right only.
- Documentation (plugins, branding, companion characters) is in English.
- The companion art generation scripts (`tools/companion_gen`) are no longer published in the repository.
