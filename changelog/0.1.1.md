# launchme 0.1.1

Released 2026-10-25.

## Fixes

- **Artwork in the desktop window** ([#1](https://github.com/uxandai/launchme/issues/1)): the desktop grid shows
  posters, but *Change artwork* opened on the square cover used by TV mode, so a picked image never reached the
  desktop card. It now opens on *Poster*, and the new poster replaces the card when the dialog closes.
  *Retry artwork*, re-identifying a game and removing its artwork refresh posters too.
- **EA sign-in** ([#2](https://github.com/uxandai/launchme/issues/2)): EA refused signing in on the token page
  Launchme opened ("Your request cannot be completed. Service limitations apply."). *Connect* now opens EA's
  own sign-in (`www.ea.com/login`) and the token page; sign in, reload the token tab and paste it. The paste
  also accepts the page with the browser's own text around it or an address carrying `access_token=`.
  No EA app needed.

## Changes

- **Default game action is Details**: picking a game (Enter, A, double click) opens its details in every view,
  the desktop window and PSfive included. Play buttons still start the game directly; switch back in
  Settings → Library → Default game action.
- **New launch screen**: starting a game shows its background, slightly dimmed and slowly zooming in, with its
  logo (or title) for about 10 seconds while the game opens. `Esc` / B hides it. Always on; its switch is gone.
- **Flix**: resting on a game in a category row for 3 seconds unfolds its poster into a wide card with the
  game's background, logo, primary action, rating, year, playtime and genres.
- README screenshots.
