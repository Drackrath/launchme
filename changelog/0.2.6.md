# launchme 0.2.6

Released 2026-10-27.

## New

- **Brazilian Portuguese and Spanish** (Settings → System → *Language*: *Português (Brasil)*, *Español*;
  *System* picks them when Windows uses Portuguese or Spanish). The whole interface is translated. Steam game
  descriptions and dates come in that language too. The AI companion and Tarot speak English.
- **Epic's own art for Epic account games**: the box art from Epic's store catalog is the game's poster, and
  its cover, background and logo where SteamGridDB has none. It needs no SteamGridDB key and downloads
  quickly, so an Epic library shows its art soon after you sign in.
- **Download artwork for selected games** (desktop window): select games with `Ctrl+A` or
  `Ctrl`/`Shift`+click, then right-click for:
  - *Download artwork again* (also a button in the pane), which asks again for every missing or failed image;
  - *Download missing covers…*, which runs the missing-covers download for just those games.

## Changes

- Missing artwork downloads faster in the background:
  - covers and posters come before backgrounds and logos (the poster first when the tiles are posters);
  - two downloads run at once instead of one;
  - a game SteamGridDB does not know is looked up once, not again for each kind of image.
- With *Video sound* set to *Muted* (Settings → Sound), the menu music keeps playing under a game's video.
- Publishers and developers are listed alphabetically, unless you moved them yourself (*Move up* /
  *Move down*).
