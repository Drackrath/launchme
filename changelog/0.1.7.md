# launchme 0.1.7

Released 2026-10-26.

## New

- **Desktop window: achievements from the details pane** — the pane's *Achievements* number opens Details on
  the game's achievements list (Back returns to Details). Hovering it highlights the number, shows a chevron
  and the hint *Show achievements*. Steam games and games the Achievements plugin knows (GOG, Epic, emulated);
  a game without achievements ("—") has nothing to click.
