# launchme 0.1.6

Released 2026-10-26.

## Fixes

- **Achievements outside Steam in the desktop window**: the details pane never asked the Achievements plugin,
  so GOG, Epic and emulated games showed "—" until their Details were opened. The pane now asks for the
  selected game once the selection rests; scrolling on drops the question for the game left behind.
- **RetroAchievements** follows the documented web API (api-docs.retroachievements.org):
  - Authenticated with the Web API key alone; the game is found in the console's game list
    (`API_GetGameList`, with hashes), cached for a week as the API asks, instead of the emulators'
    undocumented hash lookup.
  - The console comes from the ROM's ES-DE / EmuDeck system folder first (`roms\psx`, `roms\ps2`, `roms\gc`…),
    then the platform and the extension; a zipped ROM by the file inside.
  - Disc games (PlayStation, PlayStation 2, GameCube, Saturn, Dreamcast…) are matched by title, ignoring dump
    tags such as "(Europe)" or "[Disc 1]" and skipping RetroAchievements' hacks and subsets.
  - Systems RetroAchievements has no achievements for (Switch, Wii U, Wii, PS3, PS4…) are never looked up.

## Changes

- **Desktop window: narrow sidebar** shows no collections: each was the same folder icon. They are back when
  the sidebar is wide.
- The Achievements plugin is version 1.0.1; Launchme upgrades the installed copy on its next start.
