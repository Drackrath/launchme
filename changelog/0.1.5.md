# launchme 0.1.5

Released 2026-10-26.

## New

- **Achievements for games outside Steam** (the bundled *Achievements* plugin, on by default; Settings →
  Plugins). Details shows the achievements card and Szczegóły → Osiągnięcia the list, with icons, unlock
  dates and players' shares, the same as for Steam games; the counts also reach the library previews and
  the desktop pane.
  - **GOG** and **Epic Games**: with the account connected in Settings → Library. The plugin never sees
    the account's token: Launchme makes the store request with it and hands back only the answer.
  - **RetroAchievements** for emulated games: the plugin's *RetroAchievements: user name* and *Web API
    key* settings (retroachievements.org/settings). The game is found by its ROM's hash (cartridge
    systems, zipped ROMs too), else by its title.
  - **RPCS3** and **shadPS4** trophies from the emulators' own files: set *RPCS3: emulator folder* or
    *shadPS4: emulator folder*.
  - Its sources follow SuccessStory by Lacro59 (MIT); the notice ships in
    `plugin-packages/licenses/successstory.txt`.
- **Desktop window: narrow sidebar** — the new button left of the logo folds the sidebar to its icons
  (no group headings, the logo's symbol alone) and back, animated; hovering an icon names its section.
  The grid gets the room.
- **Desktop window: wider or narrower details pane** — drag its left edge (the pointer turns into ↔); the
  grid shows fewer or more columns. Double-click the edge for the default width. Both are remembered.

## Changes

- Plugin SDK: a new contribution kind and method `achievements`, with store requests the host makes for
  the plugin with a signed-in GOG or Epic account (docs/plugins/API.md).
