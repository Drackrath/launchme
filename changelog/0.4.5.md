# launchme 0.4.5

Released 2026-10-30.

## Fixes

- **A rare crash** when the launcher closed, or rebuilt its audio output after a device change, while an interface
  sound was still playing: the sound's samples were freed before its voice stopped reading them.
- **Linux: Proton games with *Write a detailed log* on** (a game's Proton i Wine options) start again: the log
  folder Proton writes into is created first.
- **Linux: launch options pasted without `%command%`** keep an argument with spaces as one argument, and
  `%command%` inside a quoted variable value is no longer taken for the game's command.
- **Linux: library order with `LANG=C.UTF-8`** (containers, minimal systems, WSL): titles sort alphabetically
  again ("alpha" before "Beta", "Łódź" before "Zelda") and numbers by value, in the library, search and the
  file browser.
- **Aurelia: *Sign in using Aurelia's window*** opens Aurelia's console again (it only closed the sign-in).
- ***Default view of collections*** and its **Reset** no longer apply to Recently played, Recently updated,
  Not played yet and the private shelf, which are not collections.
- **Deleting an own collection** also removes its library's saved view, order and filter.
- **Steam**: a library file that fails to read on every scan no longer keeps the launcher busy; it is retried
  every 30 seconds.
- **Ollama over plain HTTP** is allowed only to the home network: names such as `10.0.0.1.example.com` and public
  IPv6 addresses are no longer taken for local ones (link-local and unique-local IPv6 addresses are).
- **Downloads**: a resumed trailer download respects the size limit for the whole file; helper downloads follow
  relative redirects.
- **Game details**: a passing GOG or RAWG server error no longer hides a game's details for 30 days.
- **Save backups (Ludusavi)**: a title starting with `-` is no longer read as an option, and a failed download
  never leaves a half-unpacked Ludusavi behind.
- A name or description cut at its length limit never splits an emoji.

## Changes

- The desktop window's unused widgets popover is gone (it could not be opened; the Widgets drawer is unchanged).
- The code was reorganised (the largest files split by topic, shared helpers instead of copies, no compiler
  warnings); a map of it for contributors is in [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
- Documentation: the README and the guides cover Linux (the AppImage, the data folder, Aurelia, Amazon Games and
  Xbox there), and the plugin manifest schema accepts `linux-x64` packages.
