# launchme 0.4.1

Released 2026-10-29.

## New

- **Linux: a game's own options on top of the defaults** (a Windows game's *Proton / Wine* page): a game now keeps
  only what it changes; everything else follows the default options, also when you change them later. Each of its
  own values carries a **This game** badge: click it (or press Delete, or X on a pad) to go back to the default.
  A section's badge resets the section, **Reset all** the whole game, and **Set for this game** lists every one of
  its own values in one place. Option files of 0.4.0 are read as before.
- **Linux: compact options**: each option is one line (its name and the variable it sets) until it has the focus,
  which shows its description; the first click on a row shows it, the next one changes the value. **Search
  options** finds options, variables and DLLs by name, description or variable.
- **Linux: WINEDLLOVERRIDES as a list** (*DLL libraries*): each entry with its mode (the game's first, Wine's first,
  the game's only, Wine's only, disabled), **Add from the list** (ReShade, ASI loaders, mods), **Add by hand** and
  the whole text. Environment variables are edited by name; an emptied field removes one, or turns a default one
  off for this game only.
- **Linux: launch options as in Steam** (a Windows game's *Edit game* / *Launch options*): its whole
  WINEDLLOVERRIDES and its Proton and Wine options written as Steam does (`VAR=value gamemoderun %command% -dx11`),
  both editable by hand, so options from ProtonDB can be pasted as they are. **Proton / Wine…** beside them opens
  the game's page.
- **Linux: Protontricks for every game** (the game's *Proton / Wine* page): winetricks (its window or ready-made
  Microsoft libraries and fonts) and Wine's programs (winecfg, regedit…) with the game's own Proton or Wine,
  prefix and umu ID, for games from any store, not only Steam.
- **Linux: Extras and workarounds** (the *Proton / Wine* page): CachyOS and GE-Proton switches on a click (low-latency
  DXVK and VKD3D, OptiScaler, the game's own shader cache, cutscene fixes, DXVK for Direct3D 8, D7VK, DXVK Sarek,
  no DirectX 10/11, ray tracing in DirectX 12, integer scaling and others), lsfg-vk frame generation (*Overlays and
  wrappers*: multiplier, flow scale, performance mode) and CachyOS's `game-performance` and `dlss-swapper`.
- **Linux: ProtonDB and Steam Deck ratings** of a Windows game: in the desktop window's game details and on its
  *Proton / Wine* page, with a link to ProtonDB.
- **Linux: store launchers in a click** (Compatibility → *Stores and launchers*): Battle.net, EA app, Epic Games
  Launcher, Ubisoft Connect, Rockstar Games Launcher and GOG Galaxy, each downloaded and installed in a prefix of
  its own and added to the library.
- **Save backups through Ludusavi** (Settings → Library → *Save backups*; *Back up saves after each game* off by
  default): Launchme downloads Ludusavi on request, backs up a game's saves after it ends, and the game's menu →
  *Saves* backs them up or restores them by hand.
- **Shortcuts**: *Add to Steam* now works on Windows too (Steam sees the game run while it plays); TV mode's game
  details → … → **Shortcuts**; Settings → Library → *Game shortcuts* adds every installed game to the Start or
  applications menu, or to Steam, at once; a game removed from the library takes its shortcuts along.

## Fixes

- "No window decorations" appeared twice among the Wine options: the two are now named (Proton) and (Wine).
