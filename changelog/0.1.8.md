# launchme 0.1.8

Released 2026-10-26.

## New

- **Updates from GitHub** (Settings → System → Updates; *Check for updates* on by default): every few hours
  Launchme asks GitHub for a newer release (never while a game runs) and tells you once, pointing to
  Settings → System. Its row there, and in the desktop window an icon on the top bar, updates with one
  click: the package is downloaded next to `launchme.exe`, its SHA-256 checked, the files swapped in
  (your own plugins and settings stay) and Launchme restarts. A game in progress, a damaged package or a
  version that will not start leave everything as it was. *Check now* asks at once.
- **What's new**: the first start after an update shows the new version's changes once (scroll with the
  arrows, the stick or the wheel; OK, Enter, A or B closes it).
- **Achievement card** (Details → Achievements, TV mode and the desktop window): Enter/A or a click on an
  achievement opens its card with a larger icon, its name, the whole description, when it was earned and
  its rarity (a word, the share of players and a bar). Left/Right show the neighbours; Back, Esc, B or a
  click beside it return to the list.

## Changes

- **Installing shows its progress on the button**: Details, the library's detailed views and the desktop
  window's Details show the phase and percent with a bar (or a moving segment while the size is not
  known) instead of "Downloading in Steam", for GOG, Epic and Battle.net installs too.
