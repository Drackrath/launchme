# launchme 0.2.4

Released 2026-10-27.

## New

- **Low memory mode** (Settings → System → Performance → *Low memory mode*, on by default): Launchme uses
  much less memory. Measured on a 4K screen it uses about a third to a half less RAM and graphics memory:
  shelves 210 → 143 MB, the desktop window with 3000 games 621 → 257 MB.
  - Covers and posters are decoded at the size they are drawn on this screen, not at 1024 px. A cover
    drawn larger (the launch animation, Details) is decoded again at that size.
  - Fewer images are kept in memory: the bytes of shown artwork are not kept twice, backgrounds are kept
    only around the focused game, and long lists keep fewer bitmaps around the view.
  - While a game runs in front of the launcher (full screen on the same monitor), or the launcher is
    minimized, it gives its graphics and artwork back after a few seconds: graphics memory goes to zero and
    the RAM it keeps falls to about 100 MB. Everything comes back as soon as the launcher is in front again.
  - The Glance reader window uses less memory while inactive, and is suspended while minimized.
- **Artwork compression (BC1)** (Settings → System → Performance, under *Low memory mode*, off by default):
  artwork takes 8 times less graphics memory. It loads a little slower, and quality drops slightly.

## Fixes

- In the desktop window, after the graphics device was lost (a driver update, a GPU reset), the details
  pane could keep a background from the old device.
