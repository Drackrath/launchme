# launchme 0.3.1

Local build prepared 2026-10-27. Not published on GitHub.

## New

- **Extended Aurelia integration** (Settings → System, off by default): install/update the latest Windows x64
  helper, sign in using its console, and manage Steam games through native desktop and TV pages. Includes a
  first-run introduction and a link to Aurelia's repository.
- **Launch without Steam** (game menu → Manage · Aurelia, off by default): normal Play still uses Steam;
  opting in uses Aurelia's standalone Windows target after ownership and availability checks. Primarily for
  single-player/offline titles; multiplayer, DRM, Steamworks and Family Sharing may require Steam.
- Managed downloads, library selection, verification, moving/uninstalling, DLC, pin/unpin, manifest downgrade,
  beta branches and Workshop actions through Aurelia.
- Cloud status in desktop/TV game details, explicit conflict resolution and optional per-game synchronization
  before/after standalone play. Conflicting or incomplete pre-launch saves prevent launch.
- Native Steam friends chat through Aurelia: history, live messages, reconnect and session-scoped drafts.

## Fixes

- System keeps Updates before the Aurelia section. The language regression test locates settings by identity
  instead of relying on row numbers.
- Chat retains the selected friend's name when the friends list is replaced by the conversation.
- Cached Aurelia libraries and pending replies remain bound to their account; changing accounts clears chat state.

## Changes

- Locally combines the complete 0.3.0 artwork/tray/store/companion changes with the reviewed Aurelia branch.
- Aurelia's executable and profile are isolated; downloads are SHA-256 checked and installed atomically.
- See [the Aurelia guide](../docs/AURELIA.md) for setup and current CLI/UI limitations.
