# launchme 0.4.2

Released 2026-10-29.

## New

- **Aurelia: sign in inside Launchme** (Settings → Library → Steam → *Manage Aurelia*, desktop and TV):
  - **Sign in with a QR code** shows Steam's code on the page: scan it in the Steam Mobile app (Steam Guard → Scan
    a QR code) and approve. The code follows Steam when it changes it.
  - **Sign in with account name and password** asks for both in the page's field (the password shows as dots),
    then for a Steam Guard code from the e-mail or the app when Steam wants one, or to approve the sign-in in
    Steam Mobile. The password goes only to Aurelia and is never saved or put on a command line.
  - **Cancel sign-in** (or Back / Esc / B) stops it. *Sign in using Aurelia's window* is still there.
- **Aurelia: Steam Family Sharing**: games borrowed from your Steam Family are in the library, marked *Family
  shared* in the desktop window's details. Aurelia needs the Steam client for them, so they launch through it.

## Changes

- **Aurelia: cloud saves before and after playing are on by default**: while *Cloud saves* is on, a game managed
  through Aurelia downloads its saves before it starts and uploads them after it ends. *Sync before and after
  playing* in the game's *Manage · Aurelia* switches it off for that game.
