# launchme 0.3.2

Released 2026-10-28. Also contains the changes of 0.3.1, a local build that was not published on GitHub.

## New

- **Amazon Games** (Settings → Library → *Amazon Games*, off by default): sign in, sync the library, install,
  play and uninstall Amazon games through [Nile](https://github.com/imLinguin/nile). Nile is not bundled:
  switching the platform on offers its download (pinned v1.2.0, SHA-256 checked), and **Nile → Remove** deletes
  it again. Downloads show in **Downloads** with bytes and can be cancelled. See
  [the Amazon Games guide](../docs/AMAZON_GAMES.md).
- **Covers for manually added games** (Settings → Library → *Manually added games* → **Covers → Search**): finds
  and downloads the missing covers, posters and wide tiles of the games you added yourself, at once. Each title is
  matched on SteamGridDB, and now also on the Steam store when SteamGridDB has no match or no key is set (games in
  DRM-free folders get the same fallback).
- **Extended Aurelia integration** (Windows, optional, off by default; Settings → Library → Steam → *Manage
  Aurelia*): an optional helper ([Drackrath/Aurelia](https://github.com/Drackrath/Aurelia), downloaded on
  demand and SHA-256 checked) that manages Steam games without the Steam client. See
  [the Aurelia guide](../docs/AURELIA.md).
  - **Managed games**: Aurelia installs, updates, uninstalls and launches only the games with *Manage through
    Aurelia* on (game menu → Manage · Aurelia), or every game with *Manage games through Aurelia by default*;
    every other game keeps the Steam client. A game from the default set that needs the client launches through it.
  - Downloads in **Downloads**, library selection, verification, moving, DLC, version pinning and downgrades, beta
    branches and Workshop items, on native desktop and TV pages.
  - **Cloud saves** (on by default): a cloud button after **…** in a managed game's details and a chip in the
    desktop details pane show the status; conflicts are resolved explicitly, never automatically.
  - **Chat in the drawer**: choosing a Steam friend (the drawer's list or the desktop widget) opens the
    conversation inside the drawer; the Steam client is not started. Enter sends, Esc returns to the list; on a
    pad A types, B returns, X opens the on-screen keyboard, Y reconnects.
  - Primarily for single-player/offline games; multiplayer, DRM and Steamworks titles may need the Steam client.
- **Close game**: a ✕ next to Play in the game's details (desktop and TV) while it runs.
- **Steam account per game** (game menu → *Steam account: …*): which remembered account a Steam game starts on.
- **Exploratory Silence**, a second music theme (Settings → Sound → *Music theme*); *None* switches the music off.
  Horizons stays the default.
- Loading descriptions and facts show a soft placeholder shimmer instead of empty text.

## Fixes

- **Preloaded games**: a game downloaded ahead of its release no longer hangs at 100 % in Downloads. It is listed
  as *Preloaded*, and Play says it will be ready on the release day.
- With Aurelia on, Steam friends show their avatars again (from the Steam client's own cache, else the public
  profile), and the local Steam library is scanned as before: games installed from other remembered accounts and
  preloads appear, and "Waiting to save in Steam" no longer hangs.
- **Recently added** uses the store's acquisition date when Steam, GOG or Epic report it, instead of the day
  launchme first saw the game.
- **Change artwork**: Back sits at the top and Up/Down move between it, the types and *From disk* predictably.
- Toggling or reordering a collection in Settings changes the collection on that row.

## Changes

- Settings → Library: Steam is the first platform and can be switched off (its games, collections and friends
  leave the launcher), **DRM-free folders** second, the other stores by name, each with its mark (new Amazon
  Games and Xbox logos). Sections: Platforms, Collections (*Manage collections* first), Extra sections,
  Visibility, Launching; "My games" is now **Manually added games**.
- Settings → Media & data: **Services** comes first and ScreenScraper is inside **Service keys**.
- Settings → System: the experimental options joined **Features**.
- **Change artwork** calls the square card image **Square** (formerly Cover); **Crop** is offered for Square and
  Background only.
- Sounds: only sounds shipped with launchme or present in the chosen sound folder are offered.
