# launchme 0.3.2

Local build prepared 2026-10-28. Not published on GitHub.

## New

- **Amazon Games** (Settings → Library → *Amazon Games*, off by default): sign in, sync the library, install,
  play and uninstall Amazon games through [Nile](https://github.com/imLinguin/nile). Nile is not bundled:
  switching the platform on offers its download (pinned v1.2.0, SHA-256 checked), and **Nile → Remove** deletes
  it again. Downloads show in **Downloads** with bytes and can be cancelled. See
  [the Amazon Games guide](../docs/AMAZON_GAMES.md).
- **Games managed by Aurelia** (Settings → Library → Steam → *Manage games through Aurelia by default*, off by
  default; per game: game menu → Manage · Aurelia → *Manage through Aurelia*): Aurelia installs, updates,
  uninstalls and launches only those games; every other game keeps the Steam client. A game from the default
  set that needs the Steam client is launched through it.
- **Close game**: a ✕ next to Play in the game's details (desktop and TV) while it runs. A game Aurelia started
  is stopped through Aurelia.
- **Cloud saves button** (Settings → Library → Steam → *Cloud saves*, on by default): a cloud icon after **…**
  in the details of a managed game, and a chip in the desktop details pane, open its cloud saves.
- **Chat in the drawer**: with Aurelia, choosing a Steam friend (the drawer's friends list or the desktop
  widget) opens the conversation inside the drawer; the Steam client is not started. Enter sends, Esc returns
  to the list; on a pad A types, B returns, X opens the on-screen keyboard, Y reconnects.
- **Steam account per game** (game menu → *Steam account: …*): which remembered account a Steam game starts on.
- **Exploratory Silence**, a second shipped music theme (Settings → Sound → *Music theme*); *None* switches
  the music off. Horizons stays the default.
- Loading descriptions and facts show a soft placeholder shimmer instead of empty text.

## Fixes

- With Aurelia on, the local Steam library is scanned again: games installed from other remembered accounts
  and preloads (for example a pre-download shown as installing) appear, and "Waiting to save in Steam" no
  longer hangs.
- The file browser opened from Aurelia (*Another folder…*) is drawn above it and takes the input.
- Aurelia's library list hides false entries, shows plain paths (no `\\?\`) and the free space of each drive.
- **Change artwork**: Back sits at the top and Up/Down move between it, the types and *From disk* predictably.
- Toggling or reordering a collection in Settings changes the collection on that row, also with the manager
  row above the list.
- **Recently added** uses the store's acquisition date when Steam, GOG or Epic report it, instead of the day
  Launchme first saw the game.

## Changes

- Settings → Library: Steam is the first platform and can be switched off (its games, collections and friends
  leave the launcher), **DRM-free folders** second, the other stores by name, each with its brand mark. Aurelia
  moved here from System, onto Steam's page. Sections: Platforms, Collections (with *Manage collections* first),
  Extra sections, Visibility, Launching; "My games" is now **Manually added games**.
- Settings → Media & data: **Services** comes first and ScreenScraper is inside **Service keys**.
- Settings → System: the experimental options joined **Features**.
- Aurelia's pages follow the launcher's own style in TV mode and the desktop window, with less text.
- Sounds: only sounds shipped with Launchme or present in the chosen sound folder are offered;
  *Interface sounds* no longer shows a value.
